# Houshi Ye Participant Records

This folder contains five participant subfolders:

- `p01`
- `p02`
- `p03`
- `p04`
- `p05`

## Document format rule

For every new participant, use the same four Word document types and the same filename pattern:

- `PXX_1.1_Moderated_Usability_Observation_Sheet.docx`
- `PXX_1.2_Technical_Check.docx`
- `PXX_2.1_Post_Task_Interview_and_Quick_Evaluation_Sheet.docx`
- `PXX_2.2_Think_Aloud_Moderator_and_Coding_Sheet.docx`

Use the existing P01 files as the formatting reference. Preserve the original page size, orientation, margins, fonts, heading styles, colours, tables, borders, spacing, footer and page numbering. Fill interview-derived text in English and include transcript timestamps when available.

## Human verification rule

Do not infer or automatically select items that require direct human verification. Leave the boxes unselected for Houshi Ye to complete, including:

- task completion and assistance level;
- technical Pass or Fail results;
- release-gate checks;
- participant ratings and decision-confidence score;
- observed-use coding when the transcript does not directly establish it.

Record missing evidence as `Not recorded` or `Not verified` in the explanation field without selecting a checkbox. Never copy a previous participant's identity, date, score, technical result or observation into a new participant file.
