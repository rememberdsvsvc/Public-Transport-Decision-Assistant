# Research and Testing Documentation

This documentation is organised into three evidence streams. Keep technical verification, participant evidence, and research requirements separate when recording results.

- [Technical verification](technical/README.md): prototype logic, controlled scenarios, reproducible checks, and technical boundaries for Q2.
- [Interview testing](testing/interview/en/README.md): moderated participant tasks, observation, interview, and results templates for Q1, Q3, and Q4.
- [Requirements testing](testing/requirements/en/README.md): leverage point, committed questions, evidence plan, scope, traceability, and decisions.
