# Participant-group Variations

## Group A - General Users

Run the same T1-T4 tasks. Focus on first-use comprehension, discoverability, usability, confidence, and friction. Ask: “Before this prototype, what would you normally do?” and “After using it, what would you do now?” Treat responses as stated intentions, not behaviour change.

## Group B - Relevant-background Participants

Run the same core tasks for comparability. After T2/T3 ask: “Is the status, impact, and comparison information practical for a passenger?” “Which information is missing or ambiguous?” “Are the terms and categories understandable?” “What could happen if a passenger misunderstood this?” Distinguish direct professional experience from related academic/work background in results.

## Recruitment Fallback

Do not treat Group A as domain experts. If Group B cannot be recruited, record: “Domain/workflow validation remains a future evidence gap.”
