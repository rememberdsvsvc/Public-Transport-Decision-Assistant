# 技术核查模板

在参与者测试前使用本模板。它支持 1.2“原型与技术”问题，并将系统故障与用户错误分开记录。

| 构建版本 | 设备/模拟器 | 测试者 | 日期 |
|---|---|---|---|
|  |  |  |  |

| 情境 | 预期行为 | 实际行为 | 通过/失败 | 缺陷编号 | 复测结果 |
|---|---|---|---|---|---|
| 选择出发地、目的地、时间和完整行程。 | 所选行程打开中断信息页面。 |  |  |  |  |
| 查看一个模拟的受影响行程。 | 所选行程显示状态、受影响路段和影响。 |  |  |  |  |
| 打开决策支持并选择可用方案。 | 评价页将所选方案显示为最终选择。 |  |  |  |  |
| 提交原型评价。 | 显示提交确认；不得声称已外部提交。 |  |  |  |  |

仅对实际测试的情境记录为“证明”。通过不代表未测试行程、实时数据或外部系统也同样有效。
