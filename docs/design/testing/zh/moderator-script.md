# 主持人脚本

## 会前检查

- 原型从首页打开，构建版本和设备正确。
- 准备[会话模板](test-session-template.md)、参与者代号及已获同意的录制设置。
- 不在仓库笔记中记录姓名或其他可识别信息。

## 开场与同意

“感谢参与。我们测试的是原型，不是你；没有对错。请尽量说出你的想法，你可以随时跳过或停止。你同意参与吗？”

“我们可以录制你的屏幕和声音用于研究笔记吗？这是可选的，与参与同意分开。”记录是/否。

出声思考示例：“我在找延误信息，所以我会试试这里。”

## 前测、任务与结束

询问：“你多久使用一次公共交通？”“计划服务中断时通常会怎么做？”逐字读出[参与者任务单](participant-task-sheet.md)中的情境；不要说出控件、把标签当作指示或解释推荐选项。T2、T3 后问：“你原本预期什么？”“你的信心从 1 到 5 是多少？”

卡住时依次：安静观察；“你现在在找什么？”；“你预期这里会发生什么？”；一次中性提示“请按你觉得最自然的方式继续”；必要时直接帮助并记录。

测试后问最容易处、最困惑处、缺失信息、使用阻碍、日常做法差异和一项改进。“谢谢。我们会将去标识化笔记与其他会话一同分析以改进原型；本次不会评价你。”
