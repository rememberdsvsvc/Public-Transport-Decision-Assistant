# DECO6500 探究与证据计划

## 杠杆点

本次介入发生在乘客计划行程受中断影响后，查看影响并决定继续原行程还是选择替代方案的时刻。若介入有效，乘客能够识别相关影响并作出更有依据的下一步决定。团队选择该点，是因为现有原型直接支持这一时刻；原型不试图运营交通服务、提供实时警报或改变交通政策。

## 承诺问题

| 层级 | 评估问题 |
|---|---|
| 1.1 交互与界面 | 首次使用者能否无需直接协助完成查看中断信息和选择方案的流程？ |
| 1.2 原型与技术 | 对固定的模拟行程，原型能否稳定传递所选行程，并正确显示状态、影响和可选方案？ |
| 2.1 情境中的使用 | 在时间有限的受中断出行情境中，参与者实际使用或忽略了哪些信息来选择方案？ |
| 2.2 人的需求 | 信息是否支持参与者有信心作出出行决定，仍存在哪些不确定性？ |

记录到 A3：运营方/服务后果、数据治理、无障碍公平性和长期交通结果。不得声称 A2 已回答这些问题。
