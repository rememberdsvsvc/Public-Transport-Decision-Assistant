# 测试应急方案

## 原型不完整或模拟功能

应用使用本地 SQLite 模拟数据。告知参与者：“该原型中的中断与行程数据为模拟数据。”只测试最高可用保真度；不要暗示发生真实行程搜索、实时警报或外部提交。记录此局限。

## 其他情况

- **只有普通用户：** 执行核心可用性测试；不要让其认可交通运营，并记录 B 组证据缺口。
- **十分钟版：** 1 分钟同意与出声思考；3 分钟 T1；3 分钟合并 T2/T3；2 分钟 T4 或最终信心/反馈；1 分钟结束。优先 T1-T3。
- **远程测试：** 参与者自行操作并共享屏幕；主持人观察并记录时间；仅获同意后录制。
- **技术故障：** 与用户错误分开记录。不要绕过故障来教学；无法尝试时标记任务无效并在可行时重新安排。
- **极小样本：** 只报告形成性的定性模式；不要报告统计验证。
- **情境措辞不清：** 可中性澄清现实情境，但不得说出界面操作；记录澄清后是否仍困惑。
