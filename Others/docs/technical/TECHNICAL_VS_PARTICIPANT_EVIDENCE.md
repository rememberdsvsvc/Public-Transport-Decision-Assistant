# Technical vs Participant Evidence

| Question | Technical verification can establish | It cannot establish |
|---|---|---|
| Q1 | Information and controls are present; viable options can be selected. | Comprehension, misunderstanding, or independent decision success. |
| Q2 | Behaviour for tested simulated data and fixed scenarios. | Behaviour with live Translink data or infrastructure. |
| Q3 | The app can present information at the designed decision point. | When passengers need it, why, or which information they use. |
| Q4 | Decision-support features are available. | Confidence, uncertainty reduction, perceived control, or usefulness. |

Use the interview-testing folder for all human-outcome claims.
