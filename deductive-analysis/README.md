# Deductive usability analysis

This folder contains the final deductive usability analysis for the Public Transport Decision Assistant.

## Scope

- Participants: P01 to P15
- Analysis type: deductive thematic analysis
- Framework: Nielsen's ten usability heuristics
- Additional required category: Does not fit the framework
- Primary analysis tool: NVivo

## Files

- `Deductive_Findings_Final_P01-P15.docx`: final method, findings, claim boundaries and design priorities.
- `Matrix_Coding_Query_Final_P01-P15.xlsx`: participant by code matrix exported from NVivo.

## Main findings

1. Current personal impact is the basis for trust and action.
2. The intervention should be selective and fit familiar journey planning.
3. Transparent comparison reduces reasoning burden while preserving control.

## Interpretation

Participant presence reports whether at least one relevant passage was coded for that participant. It does not represent severity or statistical prevalence. Multiple references from one participant count once in this summary.

The evidence suggests that the prototype should explain the personal effect of a disruption, show a small set of realistic alternatives and explain recommendation order. The study cannot establish whether error recovery works because no participant case contained evidence for that heuristic.

## Data handling

This upload package excludes raw transcripts, participant quotations, consent material, recordings and the NVivo project file. Those materials should remain in the team's approved restricted storage. If the repository is private and the course team has approved research-data storage there, evidence exports can be stored separately with the required access controls.
